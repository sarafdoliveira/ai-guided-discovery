# Visit.org · AI Search prototype

Interactive prototype of an AI-assisted discovery flow for Visit.org, a platform for corporate volunteering experiences.

**Live demo:** https://YOUR-USERNAME.github.io/REPO-NAME/

## What you can try

- Type in the search bar (or pick a suggestion) to start an AI search
- Watch the loading state, then browse the matched results
- Open an experience to see its full details in a side sheet
- Bookmark experiences and view them under **Saved**
- Revisit earlier searches under **Search history**

Deep links: `?screen=results` opens the results, and `?screen=results&card=r1` opens the results with the first experience's details showing.

## About

Designed by Sara Oliveira. Built for a 1280×900 window and scales down to fit smaller screens. The prototype is a single self-contained `index.html` (no build step) and resets on reload. Nonprofit names and experience content are illustrative.
